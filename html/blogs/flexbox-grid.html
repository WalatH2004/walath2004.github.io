Flexbox of CSS Grid?

21 september 2026

Wat is Flexbox?

Flexbox is een manier om elementen makkelijk naast elkaar of onder elkaar te zetten. Tijdens het maken van mijn portfolio heb ik Flexbox bijvoorbeeld gebruikt voor mijn navigatiebalk en om tekst en afbeeldingen naast elkaar te plaatsen. Ik vond het vooral handig dat je met dingen zoals justify-content, align-items en flex-direction snel kunt bepalen waar elementen moeten komen te staan. Daardoor hoef ik minder vaak met losse marges te werken om alles op de juiste plek te krijgen.

Wat is CSS Grid?

CSS Grid gebruik ik vooral wanneer ik meerdere rijen en kolommen nodig heb. Bij mijn projecten en blogs vond ik dit handig, omdat ik verschillende onderdelen netjes naast en onder elkaar kon zetten. Zo kon ik bijvoorbeeld meerdere projectkaarten in hetzelfde overzicht plaatsen zonder dat ik elk onderdeel apart hoefde te positioneren. Voor mij voelt Grid daarom vooral handig bij grotere layouts met meerdere vakken.

Wat is het verschil?

Ik heb geleerd dat Flexbox vooral handig is als ik elementen in een richting wil uitlijnen, dus bijvoorbeeld alleen naast elkaar of alleen onder elkaar. Grid vind ik juist handiger wanneer ik tegelijk met rijen EN kolommen werk. Daardoor wordt mijn CSS voor mijzelf ook duidelijker en overzichtelijker.

Hoe pas ik dit toe?

In mijn portfolio gebruik ik Flexbox bijvoorbeeld voor mijn navbar, omdat ik daarmee de titel en de navigatielinks makkelijk naast elkaar kan zetten. Ook gebruik ik Flexbox op andere plekken waar ik tekst en afbeeldingen naast elkaar wil plaatsen. Grid gebruik ik vooral bij mijn projectkaarten en blogonderdelen, omdat ik daar meerdere onderdelen netjes in rijen en kolommen wil verdelen. Door Flexbox en Grid op deze manier te gebruiken, blijft mijn layout overzichtelijk.
